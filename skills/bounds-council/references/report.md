- Label each seat with its provider, the model the host reported running (or the requested model, marked as not reported), and the reasoning level. Keep local paths, hostnames, and environment names out.
- Write `no score` when a seat gave none; never invent one. Mark a non-blocking seat's late feedback as late and unscored.
- After the table, give one line per open dispute or declined finding, if any.
- In a PR, place the section before the closing model and harness line. Edit the description rather than posting a comment, and replace the section on later rounds instead of adding another.
- Without a PR, put the same table in the final reply.
